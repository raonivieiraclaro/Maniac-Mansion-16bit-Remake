# Maniac Mansion 16-Bit Remake — Android prototype

**Remake by Raoni Claro**

Initial **original-content technical prototype** built in Godot 4.3. Touch/click navigation, an original strong character Raoni, a movable heavy crate, intro/outro text, and seven selectable languages (PT, EN, ES, JA, DE, ZH, FR).

## Run
Install Godot 4.3+ and open `project.godot`. Press F6/F5 to run the scene/project. For Android APK export, configure Android export templates, SDK, signing and an Android export preset.

## Status
Early prototype, **not** a complete Maniac Mansion remake or an APK. Art is placeholder vector geometry. No copyrighted NES/SNES sprites, music or branded logos are included. Music and full scenes remain to be developed. A faithful adaptation requires appropriate permissions from rights holders.
